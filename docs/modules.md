# Модули

- `akcp-core` — доменные модели, контракты и общие типы
- `akcp-library` — библиотека контента: CRUD, теги, пагинация
- `akcp-ingestion-web` — ручной web‑ингест, парсинг изображений
- `akcp-publishing-vk` — постановка job на публикацию VK (заглушка)
- `akcp-jobs` — хранение и выполнение фоновых задач
- `akcp-auth` — JWT‑аутентификация и роли
- `akcp-app` — Spring Boot приложение, конфигурация, миграции
